Sobre git

Sobre git dicutimos o funcionamento do git, o que é o workcopy, stage, repositorio. Os comandos git utilizados são listados abaixo:

  • git init |cria um repositorio git vazio .git
  • git status |exibe o estado do rep.
  • git add |adiciona no stage
  • git commit -m "msg" |faz um commit
  • git config user.name "Gustavo Schwabe Razera"
  • git config user.email "schwaberazeragustavo@gmail.com"
  • git log |lista os commits da branch(ramo)atual
