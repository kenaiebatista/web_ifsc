# Lista Flexbox - PPI

Repositório com as atividades da lista de **Flexbox** da disciplina **Programação para Internet**, do
Instituto Federal de Santa Catarina (IFSC), professor Romulo Beninca.

## Arquivos

- `1-flexfroggy.html` - registro dos níveis jogados do [Flexbox Froggy](https://flexboxfroggy.com/), com explicação detalhada de 2 níveis acima do 10.
- `2-mobile-card.html` - reconstrução do card mobile (logo, linhas de texto e avatar) usando flexbox em coluna.
- `3-user-list.html` - lista de usuários (avatar + nome + endereço) com dados de `randomuser.me`, construída com flexbox.
- `4-image-gallery.html` - galeria de imagens que expande o painel sob o mouse, usando `flex` e `transition`.
- `5-holy-grail.html` - layout clássico "holy grail" (header, article, aside, nav, footer) com flexbox e `order`.
- `6-grid-boxes.html` - layout de blocos coloridos com CSS Grid, responsivo (empilha em lista vertical abaixo de 600px).

## Como visualizar

Abra qualquer um dos arquivos `.html` diretamente no navegador.
