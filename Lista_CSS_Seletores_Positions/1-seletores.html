Atividade 1 - Seletores CSS (CSS Diner)

Jogo jogado: CSS Diner, um jogo que ensina seletores CSS pedindo para "selecionar" pratos, garfos e outros itens de uma mesa (representada em HTML) usando apenas CSS. A tabela abaixo resume o seletor usado em cada nível e o que ele faz, servindo como registro/gabarito de todos os níveis jogados.

Solução resumida de todos os níveis do CSS Diner
NívelSeletor utilizadoO que o seletor faz
Seletores básicos
1plateSeleciona todos os elementos do tipo plate (seletor de tipo/tag).
2.smallSeleciona todos os elementos que têm a classe small.
3#outsideSeleciona o único elemento com o id outside.
4.small, .mediumAgrupamento: seleciona todos os elementos com classe small OU medium.
5table plateCombinador descendente: seleciona plate que estejam dentro de table, em qualquer nível.
6.small.roundClasses concatenadas: seleciona o elemento que tem AMBAS as classes small e round.
7table > plateCombinador filho direto: seleciona apenas os plate que são filhos diretos de table.
8*Seletor universal: seleciona absolutamente todos os elementos da página.
Combinadores de irmãos
9.small + .smallIrmão adjacente: seleciona o .small que vem logo depois de outro .small.
10.small ~ .mediumIrmão geral: seleciona todo .medium que venha depois de um .small, no mesmo nível (não precisa ser o próximo).
Pseudo-classes estruturais
11:first-childSeleciona o elemento que é o primeiro filho do seu elemento pai.
12:only-childSeleciona o elemento que é o único filho do seu pai.
13:last-childSeleciona o elemento que é o último filho do seu pai.
14:nth-child(odd)Seleciona os filhos em posição ímpar (1º, 3º, 5º...) dentro do pai.
15:nth-last-child(2)Conta as posições de trás para frente: seleciona o penúltimo filho.
16:first-of-typeSeleciona o primeiro elemento daquele tipo/tag entre os irmãos, ignorando outros tipos.
17:nth-of-type(odd)Seleciona, contando só entre elementos do mesmo tipo, os que estão em posição ímpar.
18:emptySeleciona elementos que não têm nenhum filho (nem texto) dentro deles.
Negação e atributos
19:not(.small)Seleciona tudo que NÃO tenha a classe small.
20[for]Seleciona qualquer elemento que possua o atributo for, independente do valor.
21[for="mom"]Atributo com valor exato: for tem que ser igual a "mom".
22[for~="mom"]Atributo contém a palavra "mom" em uma lista de valores separados por espaço.
23[for*="om"]Atributo contém a substring "om" em qualquer parte do valor.
24[for^="s"]Atributo cujo valor começa com "s".
25[for$="m"]Atributo cujo valor termina com "m".
Pseudo-elementos e desafios finais
26::first-letterPseudo-elemento: seleciona apenas a primeira letra do conteúdo de texto do elemento.

28.round:not(.small)Combinação de classe com negação: redondo, mas não pequeno.
29plate ~ .smallCombinação de tipo com combinador de irmão geral.

Explicação detalhada de 2 níveis avançados (acima do nível 10)

Nível 17 - :nth-of-type(odd)

Esse nível pede para selecionar itens em posições ímpares, mas contando apenas entre os elementos do mesmo tipo, e não entre todos os irmãos. A diferença para o :nth-child() é importante: se, por exemplo, dentro de uma mesa (table) existem um cup seguido de vários plate, o :nth-child(odd) conta a posição geral do elemento entre TODOS os irmãos (contando o cup na contagem), enquanto o :nth-of-type(odd) ignora o cup e conta apenas a posição do elemento dentro do grupo de elementos plate. Isso evita que a contagem "quebre" quando existe um elemento de outro tipo no meio dos irmãos, o que é muito útil em layouts reais como listas de produtos onde, às vezes, existe um banner ou anúncio intercalado entre os itens.

Nível 22 - [for~="mom"]

Esse nível usa um seletor de atributo com o modificador ~=, que verifica se o valor do atributo é uma lista de palavras separadas por espaço e se uma dessas palavras é exatamente "mom". É diferente do seletor [for*="mom"] (contém a substring "mom" em qualquer lugar do texto) e também diferente de [for="mom"] (o valor inteiro do atributo precisa ser exatamente "mom", nada mais). Por exemplo, um elemento com for="dad mom" seria selecionado por [for~="mom"], mas não por [for="mom"]. Esse comportamento é o mesmo usado internamente pelo próprio CSS para interpretar o atributo class (que também é uma lista separada por espaços), o que explica por que .classe funciona mesmo quando o elemento tem várias classes.
