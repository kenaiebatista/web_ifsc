# Lista CSS 1 - Seletores, Especificidade e Positions (2025-1)

Repositório com as atividades da lista de **Seletores CSS, Especificidade e Display/Position** da
disciplina **Programação para Internet**, do Instituto Federal de Santa Catarina (IFSC), professor
Romulo Beninca.

## Arquivos

- `1-seletores.html` - registro dos seletores usados em todos os níveis do jogo [CSS Diner](https://flukeout.github.io/), com explicação detalhada de 2 níveis avançados (acima do nível 10).
- `2-seletores_especifidade.html` - reprodução do exemplo de especificidade de seletores do enunciado, com explicação de qual regra é aplicada em cada item da lista e por quê.
- `3-pratica_seletores.html` - página com título e parágrafos de "Lorem Ipsum", cada um com fonte/cor diferente e palavras destacadas com `<span>`.
- `4a-display-.html`, `4b-display-.html`, `4c-display-.html` - reconstrução dos três layouts de exemplo (display padrão, display em linha e position absolute), cada um com explicação de por que a exibição ocorre daquela forma.
- `5-perfil.html` - reconstrução da página de perfil (currículo/cartão de perfil), usando flexbox para as colunas e position para os detalhes da timeline de experiência.
- `6-barquinho.html` - cena animada com CSS puro (barquinho balançando e navegando, mar com ondulação animada e nuvem atravessando o céu), usando `@keyframes`, `position` e `z-index`.

## Como visualizar

Abra qualquer um dos arquivos `.html` diretamente no navegador, ou acesse pelo GitHub Pages depois de
publicado.
