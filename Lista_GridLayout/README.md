# Lista Grid Layout - PPI

Repositório com as atividades da lista de **CSS Grid Layout** da disciplina **Programação para
Internet**, do Instituto Federal de Santa Catarina (IFSC), professor Romulo Beninca.

## Arquivos

- `1-gridgarden.html` - registro dos níveis jogados do [Grid Garden](https://cssgridgarden.com/), com explicação detalhada de 1 nível.
- `2-layout-header-nav-content-footer.html` - layout ocupando 100% do viewport com header, nav, content e footer, usando `grid-template-areas`.
- `3-layout-abcefgmij.html` - layout com os blocos A, B, C, E, F, G, M, I, J, combinando um grid externo com um grid aninhado.
- `4-responsive-media.html` - layout responsivo com `@media screen`, alternando entre um layout de 3 colunas (desktop) e uma coluna única empilhada (mobile).
- `5a.html` - site responsivo com links para os tópicos estudados (WEB, HTML, CSS, Animate, Position, Flex e Grid), que também empilha em lista vertical abaixo de 600px.

## Como visualizar

Abra qualquer um dos arquivos `.html` diretamente no navegador. O arquivo `5a.html` tem links relativos
para as outras pastas da lista (`ListaHTML`, `Lista_CSS_Seletores_Positions`, `Lista_Flexbox`), então
funciona melhor se todas as pastas estiverem lado a lado dentro do mesmo repositório.
