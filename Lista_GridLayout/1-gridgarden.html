Atividade 1 - CSS Grid Garden

Jogo jogado: Grid Garden. Cada nível pede para regar (background) e crescer (grow) as cenouras usando propriedades de CSS Grid aplicadas ao contêiner (o canteiro) ou aos itens individuais.

Explicação detalhada de 1 nível

Nível 8 - grid-column: 2 / span 2;

Nesse nível, a cenoura precisa crescer ocupando duas colunas do grid, começando na segunda linha de grade vertical. A propriedade usada foi grid-column: 2 / span 2;, que é um atalho para grid-column-start: 2; junto com grid-column-end: span 2;. O primeiro valor (2) indica em qual linha de grade (grid line) o item começa - não confundir com "coluna 2", pois as linhas de grade ficam entre as colunas e são numeradas a partir de 1. Já o span 2 não indica uma linha de grade fixa como destino, e sim quantas colunas o item deve atravessar a partir do ponto de início. Isso é mais prático do que escrever grid-column: 2 / 4; quando o que importa é "quantas colunas ocupar" e não necessariamente "em qual linha terminar" - a diferença fica mais clara em grids com tamanho de colunas variável, onde contar a quantidade de colunas é mais intuitivo do que calcular a linha de grade final.
