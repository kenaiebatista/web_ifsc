# PPI - Lista 1 (2026-1)

Repositório com as atividades da Lista 1 da disciplina **Programação para Internet**,
do Instituto Federal de Santa Catarina (IFSC), professor Romulo Beninca.

## Arquivos

- `1.html` - estrutura básica de HTML, diferença entre Internet e Web e um resumo da história da Web.
- `2_http.html` - explicação sobre o protocolo HTTP, com exemplo de requisição e resposta.
- `3_tabela_uf.html` - tabela com os estados brasileiros agrupados por região (rowspan) e link para a Wikipédia.
- `4_curriculo.html` - currículo pessoal em HTML, com menu de navegação interno.
- `4_contato.html` - formulário de contato.
- `style.css` - folha de estilos usada em todas as páginas.
- `imgs/` - pasta com as imagens usadas nas páginas (adicionar as fotos aqui).

## Como visualizar

Abra o arquivo `1.html` no navegador, ou acesse pelo GitHub Pages depois de publicado:
`https://SEU-USUARIO.github.io/SEU-REPOSITORIO/ppi1_lista1/1.html`
