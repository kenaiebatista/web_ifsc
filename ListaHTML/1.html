Internet x Web

A Internet é a infraestrutura física, a rede mundial de computadores interligados que transporta dados de um ponto a outro. Já a Web (World Wide Web) é um dos serviços que funciona em cima dessa infraestrutura, formado por páginas, links e conteúdos acessados por um navegador usando o protocolo HTTP. Resumindo: a Internet é a "estrada" e a Web é uma das "aplicações" que trafega nela.

História da Internet e da Web

Alguns dos principais marcos:

1969 - ARPANET
Primeira rede de computadores, criada nos Estados Unidos, conectando 4 universidades.
1983 - TCP/IP
O protocolo TCP/IP vira padrão de comunicação entre redes, dando origem à Internet como existe hoje.
1990 - World Wide Web
Tim Berners-Lee, pesquisador do CERN, cria a Web para facilitar o compartilhamento de documentos entre cientistas.
1993 - Mosaic
É lançado o primeiro navegador gráfico popular, permitindo ver imagem e texto juntos na mesma página.
2004 em diante - Web 2.0
Surgem as redes sociais e sites colaborativos1, onde o próprio usuário passa a produzir o conteúdo.

Tecnologias que vieram depois para deixar a Web mais bonita e interativa:

  • CSS - estilização das páginas
  • JavaScript - interatividade e dinamismo
  • HTML5 - novas tags semânticas (section, nav, article...)

Passos que Tim Berners-Lee seguiu para criar a Web:

  1. Criou o protocolo HTTP
  2. Criou a linguagem HTML
  3. Criou o primeiro navegador/editor, o WorldWideWeb
  4. Criou o primeiro servidor Web
