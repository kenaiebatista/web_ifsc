O protocolo HTTP

O que é o HTTP

HTTP (Hyper Text Transfer Protocol) é o protocolo usado pelo navegador (cliente) e pelo servidor para trocar informações na Web. Ele define como uma página, imagem ou qualquer outro arquivo é pedido e devolvido pela rede. O HTTP roda em cima do TCP/IP, normalmente nas portas 80 (HTTP) e 443 (HTTPS, a versão com criptografia).

Funciona sempre no modelo requisição / resposta:

Cliente (navegador) → envia uma requisição (request) → Servidor Web

Servidor Web → devolve uma resposta (response) → Cliente (navegador)

Principais métodos HTTP

  • GET - pedir/buscar um recurso (ex: abrir uma página)
  • POST - enviar dados para o servidor (ex: enviar um formulário)
  • PUT - atualizar um recurso existente
  • DELETE - remover um recurso

Exemplo de uma requisição real

Abrindo o navegador, apertando F12 e indo na aba Network, dá pra ver os detalhes de cada requisição feita pela página. Exemplo de requisição ao acessar um site: 

GET /index.html HTTP/1.1
Host: www.exemplo.com.br
User-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64)
Accept: text/html,application/xhtml+xml
Accept-Language: pt-BR,pt;q=0.9
Connection: keep-alive

E a resposta que o servidor devolve:

HTTP/1.1 200 OK
Content-Type: text/html; charset=UTF-8
Content-Length: 4521
Server: nginx
Cache-Control: max-age=3600

obs: capture uma requisição real sua no F12 do navegador e troque pelo exemplo acima.

Requisição (request)

Campos da requisição
CampoO que significa
Método (GET)Ação que está sendo pedida ao servidor
/index.htmlCaminho do recurso pedido
HTTP/1.1Versão do protocolo usada
HostDomínio/servidor de destino
User-AgentInforma qual navegador/sistema está fazendo o pedido
AcceptTipos de conteúdo que o cliente aceita receber

Resposta (response)

Campos da resposta
CampoO que significa
200 OKCódigo de status: pedido foi atendido com sucesso
Content-TypeTipo do conteúdo devolvido (html, json, imagem...)
Content-LengthTamanho do conteúdo em bytes
ServerSoftware do servidor que respondeu
Cache-ControlRegras de cache do navegador para esse conteúdo
